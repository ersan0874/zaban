# Static audio (Phase 12)

Placeholder pronunciation clips served at `/audio/*` (outside `/api`).

| File | Use |
|------|-----|
| `abandon.wav` | Normal-speed listening exercise audio |
| `abandon-slow.wav` | Slow playback (MVP: same tone, lower pitch/longer) |

Regenerate with:

```bash
node scripts/generate-audio.js
```

Replace with real TTS or recorded clips in later phases.
