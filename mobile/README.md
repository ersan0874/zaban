# Zaban Mobile (Flutter)

اپلیکیشن فلاتر مسیر یادگیری واژگان کنکور ارشد.

## اجرا

```bash
cd mobile
flutter pub get
flutter run
```

## ساختار

```
lib/
  models/          # WordModel, QuestionModel
  screens/path/    # نقشه زیگزاگ + BottomSheet
  screens/study/   # PageView مطالعه واژگان
  screens/quiz/    # آزمون ماژولار
  data/            # داده نمونه هم‌تراز با seed بک‌اند
  theme/           # پالت و تایپوگرافی
```
