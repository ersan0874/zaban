# واژه‌نامه Zaban

| واژه | معنی ساده |
|------|-----------|
| Path | جاده یادگیری؛ نقطه‌ها پشت‌سرهم |
| Course | یک دوره کامل (مثلاً واژگان کنکور) |
| Section / Chapter | سرفصل بزرگ داخل دوره |
| Unit / Milestone | یک ایستگاه روی Path |
| Lesson | یک درس کوتاه ۳–۵ دقیقه‌ای |
| Exercise | یک سؤال/تمرین داخل درس |
| Thin Client | گوشی فقط نمایش می‌دهد؛ مغز کار روی سرور است |
| Session | بلیت موقت برای گرفتن تمرین‌های یک درس |
| SRS | سیستم «یادت نره»؛ کلمات سخت را دوباره می‌آورد |
| Energy | سوخت بازی؛ بدون آن درس جدید سخت است |
| Combo | چند جواب درست پشت‌سرهم |
| Streak | چند روز پشت‌سرهم آمدن به اپ |
| Streak Freeze | یک بار استریک را نجات می‌دهد اگر یک روز نیایی |
| Hearts | جان؛ با غلط کم می‌شود |
| XP | امتیاز تجربه |
| Gems | الماس درون‌برنامه‌ای |
| Quest | مأموریت روزانه |
| League | رقابت هفتگی با دیگران |
| Mastery | عدد ۱ تا ۱۰۰ که بلدی چقدر است |
| Checkpoint | امتحان دروازه برای باز شدن مرحله بعد |
| Loot Box | جعبه جایزه |
| Badge | نشان افتخار |
| IAP | خرید داخل اپ با پول واقعی |
