```
- رفع:
```

## باز

### BUG-001 — اختلاف ساعت Docker Postgres با Node روی ویندوز
- وضعیت: open
- شدت: low
- فاز مرتبط: 7
- بازتولید: `NOW()` داخل کانتینر با `Date.now()` روی هاست چند ساعت اختلاف دارد؛ تست دستی regen با `NOW() - interval` ممکن است صفر بماند.
- انتظار: ساعت یکسان
- واقعیت: ممکن است clock skew باشد
- رفع پیشنهادی: همگام‌سازی ساعت میزبان/کانتینر؛ یا محاسبه regen با زمان DB (اختیاری فاز بعد)

### BUG-006 — سؤال چندگزینه‌ای هوش مصنوعی متن سؤال را نشان نمی‌داد

- فاز مرتبط: 18–19
- بازتولید: درس تولیدشده از فصل ۱؛ سؤال چندگزینه‌ای فقط «گزینه صحیح را انتخاب کنید» و گزینه‌ها را نشان می‌داد.
